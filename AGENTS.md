# Project context: Наши_путешествия

## Purpose
Этот проект находится в рабочей папке Дениса. Перед началом работы изучи структуру проекта, README, package.json, конфиги и существующие документы.

## Workflow
- Работай аккуратно и точечно.
- Сначала анализируй, потом меняй.
- Не удаляй файлы без подтверждения.
- Не трогай .env, токены, ключи, базы, recovery codes и приватные данные без прямого разрешения.
- Перед массовыми изменениями покажи план.
- После изменений запускай доступные проверки: lint, test, build.

## Local rules
- Учитывай глобальные инструкции из ~/.codex/AGENTS.md.
- Если рядом есть CLAUDE.md, README.md, docs или заметки проекта — прочитай их перед работой.
- Если проект связан с сайтом, ботом, CRM, дизайном или контентом — сначала сохрани текущий стиль и архитектуру.
