# Tech Context — Наши путешествия
> Обновлено: 2026-06-16

## Контекст
Технический пайплайн сборки путеводителей: оркестратор (Opus) + агенты Sonnet + генерация фото + HTML-вёрстка.

## Якоря — пайплайн
1. Опрос клиента через AskUserQuestion: состав / бюджет (потолок!) / транспорт (считать бензин?) / жильё (снято?) / интересы.
2. Параллельно 4 агента Sonnet (general-purpose, model: sonnet), каждый пишет в `research/*.md` и возвращает выжимку:
   - **events** — афиши строго на даты (web search)
   - **places** — достопримечательности/еда/сувениры под состав
   - **budget** — смета: бензин/платка, музеи, парковка, еда
   - **telegram** — местные ТГ-каналы через `https://t.me/s/<username>` (WebFetch) — дают то, чего нет на афишах
   - (доп.) **nearby** — что рядом/по дороге; **food** — расширенный гастро-гид с бронями
3. Синтез одного `guide.html` по дням, строго в бюджет.

## Якоря — генерация фото (kie.ai)
- Модель **nano-banana-2**, resolution 2K, output png → конвертация в WebP (`cwebp -q 82`).
- Скрипт на Python (urllib): createTask → polling recordInfo (state success) → download-url → скачать. Удалять png и gen.py после.
- Промпты — на английском, «Photorealistic … travel/food photography», aspect 16:9 (баннеры) / 1:1.
- Картинки лежат в `<поездка>/images/*.webp`, ссылки в HTML относительные `images/X.webp`.
- АПИ-ключ kie.ai — в глобальном ~/.claude/CLAUDE.md.

## Якоря — вёрстка guide.html (v2, эталон)
- Одностраничный HTML, тёплая палитра, шрифты: serif заголовки (Georgia), sans тело. **База 17px** (крупно — по требованию клиента).
- Блоки: sticky nav, hero (фон-фото + градиент), полоса stats, секция «Дорога», **светлый** блок «Находки из Telegram» (тёмный режет глаза — переделан на светлый), дни (.day с фото- или plain-заголовком), еда, смета (таблица тарифов), чек-лист, footer.
- SVG-иконки спрайтом (`<symbol>` + `<use>`).
- Сборка файла — **чанками через `cat >>` heredoc** (правило ≤200 строк на блок), затем splice новых секций через python (`s.index(...)`).
- Проверка: баланс `<section>`/`</section>`, наличие всех `images/*.webp`.

## Якоря — закрытия/проверка контента
- Маршрут строить с учётом выходных дней музеев (см. trips-context.md).
- Цены/события агенты помечают источником + датой проверки; в footer — дисклеймер про уточнение перед поездкой.
