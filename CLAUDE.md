# Наши путешествия — семейные поездки

Проект-оркестратор: собираю красивые HTML-гайды по семейным поездкам в заданный бюджет.
Я (Claude Opus) — оркестратор. Ресёрч делают агенты на Sonnet, я синтезирую в финальный HTML.

## Пайплайн сборки гайда
1. Опрос пользователя: бюджет, состав, транспорт (бензин?), жильё (снято?), даты.
2. Параллельная разведка агентами Sonnet:
   - **events** — афиши/события/фестивали строго на даты поездки (web search)
   - **places** — что посмотреть + где поесть + сувениры, под состав группы
   - **budget** — смета под бюджет: бензин/билеты, музеи, парковки, еда
3. Синтез: один HTML-гайд по дням (презентация), строго в бюджет.

## Справочные файлы для агентов
> Читать при старте каждой сессии в этом порядке:
1. `memory/active-context.md` — текущий статус, артефакты, следующий шаг
2. `memory/trips-context.md` — вводные и якоря по обеим поездкам (бюджеты, жильё, брони, выходные дни музеев, события)
3. `memory/tech-context.md` — пайплайн (агенты Sonnet, kie.ai, вёрстка guide.html)

## Правила
- HTML-гайд: одностраничный, оформленный как презентация, разбивка по дням, итоговая смета.
- Бензин: АИ-100, расход 8–9 л/100 по трассе (Audi Q3 1.5).
- Цены/события агенты берут из веба и помечают источником + датой проверки.
- Деструктивные операции с файлами — только с явным «ок».
